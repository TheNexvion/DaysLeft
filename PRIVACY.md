# Privacy Policy

**Last updated:** August 2026

## Data Collection

Days Left does **not** collect, store, or transmit any personal data to external servers.

## Data Storage

All event data (event names and dates) is stored **locally on your device** using an SQLite database managed by the Android Room persistence library.

## Network Access

Days Left does **not** require or use network access. The app works completely offline.

## Third-Party Services

Days Left does **not** integrate with any third-party services, analytics platforms, advertising networks, or cloud storage providers.

## Permissions

Days Left requests **no special permissions** beyond the default permissions required by the Android operating system.

## Data Deletion

You can delete any event at any time within the app. Uninstalling the app will permanently remove all stored data.

## Children's Privacy

Days Left does not knowingly collect any information from children.

## Changes to This Policy

If this privacy policy is updated, the changes will be reflected in this document with an updated date.

## Contact

If you have questions about this privacy policy, please open an issue on the project's GitHub repository.
